ST3189 - Linear Regression Quiz (Part 2)

51. Why is it important to standardize predictors before fitting Ridge or Lasso models?

1
The Ridge and Lasso penalties are based on the size of the coefficients. If predictors are on different scales, a coefficient for a variable with a large scale might be small, while a coefficient for a variable with a small scale might be large, just due to scaling. Standardizing (e.g., to have a standard deviation of one) puts all predictors on a common scale so the penalty is applied equitably.
Shrinkage Methods(3).html

52. In the context of the bias-variance trade-off, a very complex model (e.g., a high-degree polynomial) is likely to have:

0
Complex, flexible models make fewer assumptions about the true form of the function, so they tend to have low bias. However, they are very sensitive to the specific training data and can change dramatically with a new dataset, leading to high variance.
ISLP_website-1-pages-2.pdf, Section 2.2.2

53. What does a VIF (Variance Inflation Factor) value of 1 indicate for a predictor?

1
The VIF measures how much the variance of an estimated regression coefficient is increased because of collinearity. A VIF of 1 is the baseline, indicating that there is no correlation between this predictor and any others. Values greater than 5 or 10 are often considered problematic.
ISLP_website-1-pages-3.pdf, Section 3.3.3

54. When using polynomial regression, what is a major risk of choosing a very high degree for the polynomial?

2
Using a high-degree polynomial allows the model to be extremely flexible, but this flexibility can lead to overfitting. The fitted curve may pass very close to the training data points but can exhibit wild oscillations and erratic behavior, particularly near the minimum and maximum values of the predictor.
The Linear Regression Model.html

55. What is the primary advantage of using cross-validation to select the tuning parameter \(\lambda\) in Ridge or Lasso regression?

1
Cross-validation, particularly k-fold cross-validation, provides a more stable and less biased estimate of the test error compared to a single validation set. This leads to a more reliable selection of the optimal tuning parameter \(\lambda\).
Shrinkage Methods(3).html

56. If a residual plot (residuals vs. fitted values) shows a distinct U-shape, what does this suggest?

1
A clear pattern, such as a U-shape or an inverted U-shape, in the residual plot indicates that the linear model is not capturing some non-linear relationship in the data. The model is systematically under-predicting for some ranges and over-predicting for others.
ISLP_website-1-pages-3.pdf, Section 3.3.3

57. Comparing model selection criteria, which of the following tends to select the most parsimonious (simplest) model?

2
BIC tends to favor simpler models more strongly than AIC, Adjusted R-squared, or Cp. This is because the penalty for the number of parameters in BIC (which is \(\log(n) \cdot p\)) is larger than the penalty in AIC (which is \(2p\)) for any reasonably sized dataset (n > 7).
Subset Selection Linear Regression(2).html

58. In Bayesian linear regression, what is a 'conjugate prior'?

1
A conjugate prior is a prior distribution that, when combined with the likelihood, yields a posterior distribution from the same family of distributions. For example, a Normal prior for the mean of a Normal likelihood results in a Normal posterior. This is computationally convenient.
Bayesian Inference Essentials Part 1(1).html

59. What is a potential issue with using p-values from hypothesis tests for variable selection?

2
This is the problem of multiple comparisons. If you test many predictors, it's likely that some will appear significant just by chance, even if they have no real relationship with the response. Methods like stepwise selection that rely on p-values can suffer from this issue.
Statistical Inference on Linear Regression Models.html

60. How does the degrees of freedom of a regression spline relate to its flexibility?

1
The degrees of freedom of a spline are a measure of its flexibility. A higher number of degrees of freedom (which is related to the number of knots) allows the spline to bend more to fit the data, resulting in a more flexible but potentially overfit curve.
Spline-Based Methods.html

61. What is Cook's distance used to measure?

2
Cook's distance is a measure of the influence of an observation. It quantifies how much all of the fitted values in the model change when a particular observation is removed. Large values of Cook's distance indicate an influential point.
The Linear Regression Model.html

62. What is the difference between an outlier and a high-leverage point?

1
An outlier is a point with an unusual Y value (i.e., a large residual), meaning it is far from the regression line. A high-leverage point is a point with an unusual X value. A point can be one, both, or neither. Points that are both outliers and have high leverage are often the most influential.
ISLP_website-1-pages-3.pdf, Section 3.3.3

63. What is the purpose of the 'hat matrix' H in linear regression?

2
The hat matrix, \(H = X(X^T X)^{-1}X^T\), is so named because it 'puts a hat on Y'. The diagonal elements of the hat matrix, \(h_{ii}\), are the leverages of each observation.
Statistical Inference on Linear Regression Models.html

64. In a simple linear regression, the leverage of an observation \(x_i\) increases as:

2
For a simple linear regression model, the leverage of the ith observation is given by \(h_{ii} = \frac{1}{n} + \frac{(x_i - \bar{x})^2}{\sum_{j=1}^n (x_j - \bar{x})^2}\). This value increases as \(x_i\) moves farther from the mean \(\bar{x}\).
ISLP_website-1-pages-3.pdf, Section 3.3.3

65. What is a key advantage of Principal Components Regression (PCR) over standard least squares?

1
PCR is a dimension reduction technique. It first constructs principal components, which are linear combinations of the original predictors and are uncorrelated. By regressing the response on a small number of these components, PCR can reduce model variance and perform well in the presence of multicollinearity.
Shrinkage Methods(3).html

66. What is a potential disadvantage of Principal Components Regression (PCR)?

0
PCR is an unsupervised dimension reduction technique. It identifies the principal components based only on the variance of the predictors (X), not their relationship with the response (Y). It's possible that the directions with the most variance in X are not the directions most predictive of Y.
Shrinkage Methods(3).html

67. How does Partial Least Squares (PLS) differ from Principal Components Regression (PCR)?

1
Unlike PCR, which finds components that explain the most variance in the predictors (unsupervised), PLS is a supervised method. It finds components that not only summarize the predictors but are also related to the response variable Y. This can lead to better predictive models.
Shrinkage Methods(3).html

68. What is meant by a 'studentized residual'?

1
Standard residuals all have different variances depending on the leverage of their corresponding observation. A studentized residual is calculated by dividing the raw residual by its estimated standard error. This gives residuals that should all have approximately the same variance, making it easier to identify outliers.
The Linear Regression Model.html

69. If you have a categorical predictor with 4 levels, how many dummy variables should you include in the regression model?

1
For a categorical predictor with k levels, you should include k-1 dummy variables in the model. One level is chosen as the baseline or reference level, and its effect is captured by the intercept. The coefficients of the k-1 dummy variables represent the difference in the mean response between that level and the baseline level.
ISLP_website-1-pages-3.pdf, Section 3.3.1

70. What is a confounding variable?

1
A confounder is a variable that influences both the dependent variable (response) and independent variable (predictor), causing a spurious association. For example, if you find a correlation between ice cream sales and crime rates, the confounding variable is temperature, which affects both. Not accounting for confounders can lead to incorrect conclusions.
The Linear Regression Model.html

71. In the context of GAMs, what does the 'additive' assumption mean?

1
The 'additive' nature of GAMs means that the model does not automatically include interactions between predictors. The effect of changing one predictor on the response is the same regardless of the values of the other predictors. This makes the model easier to interpret, but interactions can be added manually if needed.
Spline-Based Methods.html

72. What is the main benefit of the elastic net penalty over the lasso penalty?

1
The lasso penalty can be somewhat indifferent when faced with a group of highly correlated variables, often selecting just one of them arbitrarily. The elastic net, which includes a ridge-like component, is more stable in this situation and tends to select the entire group of correlated variables, which can be a more desirable outcome.
Shrinkage Methods(3).html

73. A 95% confidence interval for a coefficient \(\beta_1\) is found to be [-0.1, 0.8]. What is the correct conclusion at the 5% significance level?

1
Since the 95% confidence interval contains the value 0, we cannot reject the null hypothesis \(H_0: \beta_1 = 0\) at the \(\alpha = 0.05\) level. Therefore, the coefficient is not considered statistically significant.
Statistical Inference on Linear Regression Models.html

74. What does it mean if the error terms in a time series regression are positively autocorrelated?

2
Positive autocorrelation (or serial correlation) means that the residuals are correlated with each other over time. Specifically, a positive residual (under-prediction) at time t is likely to be followed by another positive residual at time t+1. This violates the assumption of independent errors.
ISLP_website-1-pages-3.pdf, Section 3.3.3

75. In Bayesian inference, what is a 'non-informative' or 'vague' prior?

1
A non-informative prior is one that is chosen to have as little impact as possible on the final posterior distribution. The idea is to allow the information from the data (via the likelihood) to be the dominant factor in the analysis. A flat or uniform prior is a common choice, but true non-informativity can be complex.
Bayesian Inference Essentials Part 1(1).html

76. What is the primary motivation for using a log transformation on the response variable Y?

1
A log transformation of Y is often used when the data exhibits heteroscedasticity where the variance of residuals increases with the fitted values. It can also linearize a relationship of the form \(Y = \beta_0 e^{\beta_1 X}\), since \(\log(Y) = \log(\beta_0) + \beta_1 X\) is linear.
The Linear Regression Model.html

77. If the goal of modeling is pure prediction, which of the following is generally more important?

1
If the primary goal is prediction, we are most concerned with the model's ability to accurately predict unseen data. The test MSE is a direct measure of this predictive performance. Interpretability and p-values are more important when the goal is inference.
ISLP_website-1-pages-2.pdf, Section 2.1.2

78. What is the 'irreducible error' in the context of a statistical learning model?

2
The irreducible error, \(Var(\epsilon)\), represents the inherent noise or variability in the data that cannot be captured by a model, no matter how good it is. It sets an upper bound on the achievable prediction accuracy.
ISLP_website-1-pages-2.pdf, Section 2.1.2

79. In backward stepwise selection, what is the starting point?

2
Backward stepwise selection starts with the full least squares model containing all p predictors. It then iteratively removes the least useful predictor, one at a time, until a stopping rule is reached.
Subset Selection Linear Regression(2).html

80. What is a major limitation of using traditional subset selection methods (best, forward, backward) when the number of predictors p is very large, especially when p > n?

1
When p > n (more predictors than observations), the standard least squares fit is not possible because the matrix \(X^T X\) is singular. This means that backward selection cannot be used, and even forward selection and best subset selection can run into issues of perfect fits and high variance. Shrinkage or dimension reduction methods are preferred here.
Shrinkage Methods(3).html

81. The shape of the constraint region for Ridge regression is a ________, while for Lasso it is a ________.

2
The L2 penalty in Ridge regression (\(\sum \beta_j^2 \le s\)) corresponds to a circular constraint region. The L1 penalty in Lasso (\(\sum |\beta_j| \le s\)) corresponds to a diamond-shaped (or rhombus in 2D) constraint region. The sharp corners of the diamond are why the Lasso solution can hit an axis and set a coefficient to exactly zero.
Shrinkage Methods(3).html

82. In a Bayesian context, the posterior predictive distribution represents:

1
The posterior predictive distribution is used for prediction in a Bayesian framework. It represents our uncertainty about a future observation by integrating the likelihood of the new data point over the entire posterior distribution of the model parameters.
Bayesian Linear Regression.html

83. What is the main purpose of a Q-Q (quantile-quantile) plot of the residuals?

1
A Q-Q plot is a graphical tool used to assess if a set of data plausibly came from some theoretical distribution, such as a normal distribution. In regression diagnostics, it is used to check the assumption that the error terms are normally distributed by plotting the quantiles of the residuals against the quantiles of a theoretical normal distribution.
The Linear Regression Model.html

84. If the true relationship between X and Y is \(Y = X^2\), and you fit a simple linear model \(Y = \beta_0 + \beta_1 X\), the model will have:

2
The model has high bias because it is making a strong (and incorrect) assumption that the relationship is linear. It will systematically fail to capture the true quadratic nature. It has low variance because it is a simple model that will not change much if fit to a different sample of data.
ISLP_website-1-pages-2.pdf, Section 2.2.2

85. Which of the following is NOT a method for dealing with heteroscedasticity?

3
VIFs are used to diagnose multicollinearity, not heteroscedasticity. The other three options are valid approaches: transforming Y can stabilize variance, weighted least squares gives less weight to high-variance observations, and robust standard errors correct the standard error estimates to account for the heteroscedasticity.
The Linear Regression Model.html

86. In a regression model with an interaction term between a quantitative predictor X and a binary dummy variable D, what does the coefficient of the interaction term (\(\beta_3\) in \(Y = \beta_0 + \beta_1 X + \beta_2 D + \beta_3 XD\)) represent?

1
The interaction term allows the slope of X to be different for each level of the dummy variable. For D=0, the slope is \(\beta_1\). For D=1, the slope is \(\beta_1 + \beta_3\). Therefore, \(\beta_3\) represents the change in the slope of X when D changes from 0 to 1.
ISLP_website-1-pages-3.pdf, Section 3.3.2

87. What is the main drawback of k-fold cross-validation?

1
The primary disadvantage of k-fold CV is computational cost. Since the model must be refit k times, it can be slow if the model fitting process itself is time-consuming. However, this cost is often considered a worthwhile trade-off for a more accurate estimate of test error.
ISLP_website-1-pages-2.pdf, Section 2.2

88. Leave-one-out cross-validation (LOOCV) is a special case of k-fold cross-validation where:

2
LOOCV is simply k-fold cross-validation where k is set to the total number of observations, n. In each fold, one observation is held out for testing, and the model is trained on the remaining n-1 observations.
ISLP_website-1-pages-2.pdf, Section 2.2

89. Compared to 5-fold or 10-fold CV, LOOCV generally has:

0
LOOCV provides an almost unbiased estimate of the test error because each training set is very large (n-1). However, the estimates from each fold are highly correlated since the training sets are so similar. This high correlation leads to higher variance in the overall test error estimate compared to k-fold CV with a smaller k.
ISLP_website-1-pages-2.pdf, Section 2.2

90. What is the primary risk of data dredging or p-hacking?

0
Data dredging (or p-hacking) is the practice of repeatedly testing different models and predictors until a statistically significant result (e.g., p < 0.05) is found. This dramatically increases the risk of finding false positives—relationships that appear significant in the sample data but do not exist in the population.
Statistical Inference on Linear Regression Models.html

91. In a Bayesian setting, if the prior and posterior distributions are very different, what does this imply?

2
The posterior distribution is a combination of the prior and the likelihood (data). If the posterior is very different from the prior, it means the data was informative and had a strong influence, causing a significant update in our beliefs about the parameters.
Bayesian Inference Essentials Part 1(1).html

92. What is the main difference between prediction and inference?

1
Prediction focuses on generating accurate outputs (Y) for new inputs (X), treating the model as a black box. Inference focuses on understanding how the inputs affect the output, interpreting the model's coefficients and their significance.
ISLP_website-1-pages-2.pdf, Section 2.1.2

93. A key assumption of linear regression is that the predictors are...

2
In the classical linear regression model, the predictors (X values) are treated as fixed constants, not random variables. It is also assumed they are measured perfectly, without any error. The randomness in the model comes from the error term \(\epsilon\).
The Linear Regression Model.html

94. If the tuning parameter \(\lambda\) in Ridge regression is set to 0, the resulting model is equivalent to:

1
When \(\lambda = 0\), the penalty term in Ridge regression has no effect. The objective function reduces to simply minimizing the RSS (Residual Sum of Squares), which is exactly what standard least squares regression does.
Shrinkage Methods(3).html

95. As the tuning parameter \(\lambda\) in Ridge regression approaches infinity, what happens to the coefficient estimates?

1
As \(\lambda\) becomes very large, the penalty for having non-zero coefficients becomes overwhelming. To minimize the objective function, the model is forced to shrink the coefficients closer and closer to zero. In the limit, all coefficients (except the intercept) will be zero.
Shrinkage Methods(3).html

96. Which statement about the relationship between training error and test error is true?

1
The model is fit on the training data, so it can achieve a lower error on that data than it can on new, unseen test data. The training error is often an overly optimistic estimate of the model's performance on new data.
ISLP_website-1-pages-2.pdf, Section 2.1.3

97. A simple linear regression model is fit to a dataset where the true relationship is not linear. The training RSS will be ________ and the test RSS will be ________.

1
Because the model is too simple (high bias), it will not be able to fit the training data well, resulting in a high training RSS. Since it fails to capture the true relationship, it will also perform poorly on the test data, resulting in a high test RSS.
ISLP_website-1-pages-2.pdf, Section 2.2.2

98. A very flexible model is fit to a dataset. The training RSS will be ________ and the test RSS will be ________.

0
A very flexible model can fit the training data almost perfectly by following all the noise, leading to a very low training RSS. However, this is overfitting. When presented with new data, the model will perform poorly because it learned the noise, not the signal, leading to a high test RSS.
ISLP_website-1-pages-2.pdf, Section 2.2.2

99. What is the main advantage of using a smoothing spline over a polynomial or regression spline?

1
Smoothing splines elegantly sidestep the knot selection problem. They use a maximal number of knots (one at each unique data point) but add a penalty term that controls the roughness or wiggliness of the curve. The level of smoothness is then controlled by a single tuning parameter.
Spline-Based Methods.html

100. In the context of Bayesian inference, what does MCMC stand for?

1
MCMC (Markov Chain Monte Carlo) is a class of algorithms used to sample from a probability distribution. In Bayesian statistics, it is used to sample from the posterior distribution of the parameters when the distribution is too complex to calculate directly.
Bayesian Inference Essentials Part 2(1).html
